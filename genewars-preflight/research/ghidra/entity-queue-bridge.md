# Explicit family-1 draw queue

The pinned CD candidate's queue and runtime flag packets are separable from a complete mission frame. `entity-queue-evidence.json` records thirteen private listings, 225 linked-list/order comparisons, 131,072 draw-packet cases, boundary vectors and a private forty-source-point fixture. Run `python -B scripts/ghidra/validate_entity_queue_bridge.py`.

Use explicit signed32 projected coordinates from `0x7AF00`, display pitch 640, height 480, unsigned margin 0 or 128, an empty queue and caller-supplied admission sequence. Require active module `116974 == 1863A2` and a safe count in 0–256. `0x83140` admits family-1 points with `-40 <= x < 640-margin+40` and `-10 <= y < 520`, while capacity remains below 256. Its family-1 height virtual returns zero. The original only checks the signed count's upper bound; negative counts are excluded by the safe API.

For y<=0, use bucket zero and residual y, inserting by signed residual ascending with equal entries appended. For 0<y<480, use bucket y and residual zero, inserting at the head: equal-row admission order reverses. For y>=480, use bucket 479 and residual y-480, again stable ascending residual. `0x83930` traverses buckets 0–479 and each linked chain. It passes signed16 x and signed16(bucket+residual) to the draw virtual. Consequently, bottom offscreen y reconstructs as **y-1**. A generic stable depth sort would lose these behaviors.

An optional separate `0x83140` post-insertion packet is valid for native type byte +6 equal to 2 and context +0x1C mask0x01 clear (selection interaction disabled). Shade byte +0x17 zero preserves flags and does not raise the context gate +0x11D8. Positive shade raises that gate; positive signed countdown byte +0x11D6 sets flags +0x15 mask0x04. If mask0x04 is then set, mask0x08 is also set and virtual +0x70 requests dirty marking of the old cached frame. `0x1E760` suppresses that dirty call's body when the cached frame pointer is null. This packet belongs in a separate helper from queue ordering.

For family 1, virtual +0x6C always returns true. With selected entity explicitly absent, `0x83930` draws only when context +0x11D8 is nonzero and either context mode byte +0x11D5 is nonzero or entity flags mask0x08 is set. A draw uses dirty class 3 when mask0x04 is set, otherwise class 1; afterward flags are ANDed with 0xF3. A skipped entity retains flags. The pass clears queue heads, count and context gate. `0x82BD0` establishes mode 1; it does not by itself establish the context gate.

The preceding `0x83710` pass disables pixel writes and propagates dirty regions. It skips flags mask0x08, accepts mask0x04 without a dirty-bound query, otherwise tests component bounding rectangles against nonzero 32x32 dirty blocks through `0x7A900/0x7A810`. That query tests dirty blocks, not sprite opacity. Accepted dry draws set masks0x0C and restart the scan from bucket zero. This behavior is documented but excluded from the pure queue and flag-packet APIs.

Raw CONQ001 has forty active family-1 records with type2, flags0x04 and shade zero. Loader initialization establishes runtime resource pointers; `0x72960` refreshes shade, the scheduled `0x6CA90` update changes other runtime fields, and queue/dirty passes change flags. A zero-shade plant can still draw when another admitted positive-shade entity raises the shared gate. Raw source order and fields therefore do not prove a full first-scene queue. The full-table route scans family 0 before family 1, each ascending; the ordinary update route additionally depends on counts, scheduled updates and record flags. Explicit single-record or isolated-family diagnostics remain valid within their stated inputs.
