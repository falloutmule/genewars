# Family-1 plant resources and normal foreground

This is a bounded foreground contract for the hash-pinned CD executable candidate, not a complete entity renderer. `plant-color-evidence.json` binds thirteen private listings, twelve CD resources and private decoded frame receipts. Run `python -B scripts/ghidra/validate_plant_color_bridge.py` to validate it without executing game code.

The numeric mission family 1 is the 512-record table at source offset `0x43D4E`, serialized stride 41. Its native table begins at world-state offset `0x446AE`, stride 49. Reader `0x6D490` copies the first 31 bytes to native offset 0, then `0x6C950` copies the remaining ten to native offset 39. The reader changes the staging source flags and shade only after the header copy. Raw source fields are signed position words at +7/+9, byte flags +0x15, shade +0x17, animation +0x19, frame +0x1B, and signed resource selector +0x23 (native +0x2B). The source jitter flags +0x26 map to native +0x2E. Runtime pointers and the eight-byte native gap are not source fields.

Initializer `0x6C690` reads the signed native resource selector and selects `1168C4[selector]`. Twelve ordered slots bind GRASS1–3, DESERT1–3, SNOW1–3 and ALL1–3. The descriptor names, destination globals, input and decoded SHA-256 values are in the receipt. `0x1DFD0` calls `0x98A60` for each raw resource, producing an animation-table pointer. `0x1F290` selects animation `entity[0x19] * 10`, reads that animation's first-frame pointer, then adds `entity[0x1B] * 14`. The frame byte is relative to the selected animation's first frame. Safe code must check the signed selector, animation index, frame count and all section extents before caching a frame.

Loader `0x98A60` halves signed component x/y with arithmetic right shifts. The color pass does not halve them again. Its normal component placement adds each component offset to the supplied origin and narrows each result to signed 16 bits before blitting. All twelve animation-0/frame-0 fixtures have one component with flags zero; their actual dimensions and offsets are recorded separately, not assumed equal. All forty active CONQ001 family-1 source records select animation 0/frame 0, with field +0x15 equal to 4 and jitter field zero. That is source evidence, not a timing or visibility claim.

The admitted normal foreground path requires `(context[0x16E0C4] & 0x02) == 0`, `(entity[0x15] & 0x10) == 0`, `(entity[0x2E] & 0x02) == 0`, and component flags zero. Field offset +0x15 is distinct from bit number 15: mask **0x02** forces the direct color path; mask **0x10** enables flashing and is excluded here. If mask 0x02 is set or the unsigned shade byte at +0x17 is at least 30, `0x97A90` calls the indexed8 blitter `0x9A660`. Otherwise `0x97CA0` calls `0x9B0D0`, mapping each literal byte through `FADE[shade*256 + index]`. Shade 0–29 is the table domain selected by this branch; 30–255 bypasses the table.

Both color readers use signed controls: positive controls consume that many full index bytes, negative controls skip pixels, and zero ends a row. Literal index zero is opaque. Clipped runtime copies still advance the complete positive source run. Cached resource decoding validates every declared row terminator and bounds the stream before the TAB section; all twelve admitted fixtures also fit their declared widths. This does not license a general malformed-stream acceptance policy or a packed4 decoder.

`0x6C230` always requests the shadow before foreground: same resolved frame, signed16 x/y origin, ECX zero and a zero extra stack argument to `0x96AC0`. Its normal component path uses x plus signed component x, and y plus component y divided by two with truncation toward zero, then calls `0x92F80` with CL zero. The shadow raster is a separate pending contract. A foreground-only API must make that limitation explicit; it must not report the whole entity draw as complete. Visibility, sorting, animation advancement, initial active state and shade-refresh timing remain separate.
