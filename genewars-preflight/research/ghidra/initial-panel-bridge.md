Transitive child constructors `0x21940` and `0x252B0` preserve the input pointer in EAX, corroborating the subsequent root-relative module back-slot writes.

Mission entry `0x7D090` requests module `0x1863A2`. Main loop `0x1BBC0` dispatches its vtable at module+7. Constructor `0x2B7E0` binds that entry to thunk `0x30120`, which subtracts the 0x5A6 back adjustment and enters `0x2BBE0` with object `0x185DFC`. This establishes the actual startup caller rather than relying on a constructor's default alone.

Under those gates `0x2BE35` selects default child object+0xCC regardless of the previous module. Its descriptor delta 12 resolves active panel `0x185ED4`; the signed selector byte is zero. `0x24770` resolves that selector through name table `0x105604` to `data/mainpanl.dat`, allocating 61,440 bytes and loading the file.
