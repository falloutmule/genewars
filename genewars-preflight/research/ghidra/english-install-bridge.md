# English installation copy prerequisite

The exact CD DOS installer selects `ENG` for English and copies the selected language text into the installed flat path `DATA/TEXT.DAT`. The executable does not select the nested language path when loading this descriptor. Run-002 had the nested CD source tree and lacked that flat file when statically inspected; this is a concrete explanation for absent labels worth checking in a fresh staged reference run. It does not prove all text rendering or mouse motion will work afterward.

The source is manifest entry `root/2/disc/592`, `GAME/DATA/TEXT/ENG/TEXT.DAT`, 36,610 bytes, SHA-256 `23e60305a9fa028a0f6541456ab453b7e7cc439f787a2b75e4b8d088e0b01786`. The destination is `DATA/TEXT.DAT` beneath the generated InstallDrive prefix. Copy bytes unchanged; do not alter or replace the nested source.

Static chain: installer English branch `0x15EF3..0x15F0C` stores the `ENG` selector. `0x135D6..0x135EE` formats the source into table record `0x6F83C`. Its destination-directory field at record+0x90 is `DATA\`. The worker `0x170C8`, at `0x171A9..0x171CA`, formats install prefix, record destination directory, and enumerated basename; its read/write state copies the bytes. Game startup `0x1D799..0x1D7AB` loads category 5 descriptor `0x10443C` (`data/text.dat`) into `0x115E88`. Startup builds exactly 604 pointers: it decrements initial counter 0x25C and tests for -1 before each store. A safe native parser must reject missing terminators and expose any trailing bytes, rather than follow the original unchecked scan.

The same selected-language copy list flattens the 18 English `GAME/SPEECH/ENG/*.*` files to installed `SPEECH/<basename>`. These are installation-path evidence, not newly decoded audio contracts. `english-install-evidence.json` records every exact manifest ID, size, SHA-256 and destination. The maximum, medium and minimum installer lists all have the same first two language rows; remaining file-list rows preserve their relative subdirectory layout. No additional language-dependent transformation appears in these bounded lists. Driver-list language selection exists separately and is not authorization to replace sound settings or run an installer.

Validation: `python -B scripts/ghidra/validate_english_install_bridge.py` checks the exact original installer/game hashes, mapped strings and descriptor pointer, five private instruction exports, three installer lists and all 19 source/destination records. Proprietary instruction listings remain under `private/ghidra`; this note and JSON contain original behavioral metadata only. No original execution was performed in this lane.
