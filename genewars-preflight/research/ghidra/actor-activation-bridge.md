`0x80AE0` is the actual ready-state producer for newly placed actors. It visits five200-byte slots in the player's partition, in ascending order, selecting active slots with word+0x70 mask0400. It changes the word to `(old & 0xFBFE) | 1` and clears byte+0x16 mask08. It then repeatedly requests a radius512 candidate around player+9 until the original terrain and cell-plant predicate accepts it. The separate associated type5-unit branch is excluded.

`0x73E00` consumes one shared16-bit multiplicative RNG draw per candidate. The next seed is `seed * 0xE62D` modulo65536; its high byte selects one of256 angles. The exact doubled-word addition, floor shifts and15-bit masking are pinned in the validator, including boundary vectors. Both2048-entry fixed point trig tables match independently generated truncations of65536 times sine/cosine. This proves a deterministic candidate generator with an explicit live seed; it does not prove which seed arrives at landing. After acceptance, the routine writes actor position+7 and inserts its cell link. It changes the actor's blueprint metadata at+0x1B/+0x20/+0x1C and can set actor+0x72 to40 for the first category1 use. It increments player+0x49D after scanning all five slots, even with no eligible actor. It preserves actor height+0x11 and shade+0x17; recomputing them from the new point would be an invented change. Null cell references preserve unused index words according to `0x8AC60`, rather than canonicalizing them.

The safe per-slot domain admits active type3 actors only. The original loop tests any nonzero type, but other types take different placement predicates. For a nonnull cell head, `0x8AC60` obtains the next reference from the resolved old head record's ID/type fields. Treating this as a raw-head copy requires explicit ID/type consistency with the head triple, valid kind1..8 and bounded nonnegative index. Null heads admit kind0 with an opaque index word. Startup reaches this routine through the landing object with code **0x31**, rather than immediate actor readiness. `0x7F3B0` creates it above terrain with vertical speed-1088.
