# Neutral plant reproduction components

Observed in the Rust port and corroborated by closed instruction interpreters; the original program was not executed for these checks. These APIs are not yet connected to the running plant scheduler.

- `plant_spread::plan_spread_target` implements6CCF6..6CFC5 after the caller's growth, period and population gates. A hash-bound36-byte direction table drives wrapping signed-coordinate steps. Each step consumes one RNG draw; target checks run in terrain, live-plant count, obstacle-bit order. Accepted cells consume Y jitter before X jitter. The original cell's high bytes are retained. Height must exceed the explicit signed threshold plus512. Rejected targets retain their consumed RNG in the returned plan.
- `plant_factory_position` and `plan_neutral_plant_initialization` implement the neutral owner4 factory's position quantization and49-byte native fields. Prior unknown fields survive. Pointer bytes31..39 are an opaque native gap; resource selection is typed metadata. Height and shade are explicit samples at the quantized point.
- `ActorWorld::create_neutral_plant` chooses the first inactive packed slot, samples the live map, initializes the plant, inserts it at the cell head and increments the plant count atomically. It repairs an existing head's previous reference through the correct owned family. It does not mark newborns or run the reproduction scheduler.
