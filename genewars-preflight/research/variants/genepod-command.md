# Genepod opcode12 numeric command

Verified reference: QA BETA V5. `genepod_command.rs` implements a pure transaction for payload species4, completed selector0 buildings, grades0..2, valid building-slot identity and caller/funds identities0..3. Root owns module registration and host integration. These are implementation admission bounds, **not original command rejection predicates**.

Original dispatcher `1C5C2..1C5C6` calls814A0. The handler contains no research, capacity, ownership or sufficient-funds rejection and no RNG calls. Its species4 mapped cost at10461C+4*45 is75. An upstream producer must establish legal ordinary command eligibility. Human UI producer/hit target and its gates remain unresolved; test-only handler availability is not a claim of usable authentic production.

API `plan_mule_command(building67,caller1805,GenepodRequest,GenepodCommandContext)` returns building/caller afterimages plus a typed panel-refresh request. Context `funds_identity_player_type` is byte+2 of the global player indexed by **caller4A1**.4A1 is an identity, not a type byte. This type controls the start-only AI balance floor. Independently, caller+2 controls whether caller+1 is copied to building3A on both start and cancel. `selected_panel_refresh_eligible` explicitly supplies the conjunction of source module/selected-building/panel-root checks; it does not pretend21D70 was executed.

Start814F0..8153C writes work36=75>>grade, low-word initialwork34, species33=4. It debits remainder75&((1<<grade)-1) from primary4A3, then secondary4A7 using wrapping32-bit arithmetic. If the identity player's type is nonzero and signed primary+secondary<=1000, source8153F..81565 sets secondary=1000. Grade0 debit is zero. Calling start during positive work replaces work without an automatic cancellation/refund; no invented busy rejection is added.

Cancel815AF..81601 computes refund `(signextend(initialword34)-work36)*2^grade + remainder` with source wrapping. Add to secondary4A7. The cap at5E6 uses an **unsigned** comparison; on reaching/exceeding cap set secondary to cap and add overflow to primary. Then clear work36 only. Preserve species33, initialword34 and other fields. Neither action creates a creature or consumes RNG.

Independent interpreter executes literal814A0, with21D70 represented as an explicit presentation request. `genepod-command-review.py/.rs/.json` passed240 full building+caller+request cases (449,520 bytes;16,304 instructions) and1,200 unsupported-input checks. Cases cover grades0/1/2, starts/cancels, human/AI caller separately from funds-identity type, negative and overflow arithmetic inputs, primary/secondary splits, cap boundaries and panel refresh. Invalid inputs return before mutation because all outputs are pure owned copies. Original RNG seed/ring/draw count stay unchanged. This is handler numeric proof, not proof that deliberately unusual balances are legal gameplay states. No production tick, factory, research gate or native UI acceptance is included.
