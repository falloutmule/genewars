Observed static review, 2026-10-12 local: no blocking defect found in `genewars-core/src/custom_list.rs` as reviewed after the packet flag parameter became u8. Reviewed the actual exported handler instructions in `private/ghidra/ui-controls/instructions-0007e400.txt`, not only the dossier or decompiler output. Listing SHA-256 is `e09f38677a943351455b1b0c2448a47217127cd1bbb34a9861d91a5e9924b7ee`.

At VA `0x7E8DC`, the object pointer saved at entry is restored, byte +0x16 is tested and decremented only when nonzero. At `0x7E8EF`, INC operates on that byte directly. Saturating subtraction for event 27 and wrapping addition for event 28 therefore agree. No count clamp is present in these branches. The helper's None for other controls expresses its restricted scope, not the full handler's other effects.

At `0x7E8F5`, the gate is exactly one byte at global `0x19CFB6`; the revised Rust u8 argument preserves that width. Reading an adjacent u32 and testing it nonzero would have been incorrect for a low zero byte with nonzero neighboring bytes. The event is loaded with MOVSX from the global word and compared to -1. Signed dword JL/JGE checks establish x in [180,454) and y in [224,296). Only after those checks does the original subtract 224 and IDIV by 12. Rust's subtraction is consequently bounded to 0..71 and cannot overflow; its six row values 0..5 agree with signed IDIV. Zero-extended offset plus row is stored through AL to state +0x19, so modulo-256 addition is required and correctly retained.

The numeric helper deliberately stops before the unchecked string copy. The original string source is object +0x507 +selected*0xE1 +0xE, equivalent to object +0x515 +selected*225; destination is object +0x3D5. Selected=255 does not prove that record exists. Any future text/UI caller needs independent list allocation/count and bounded terminator evidence before indexing or copying. A sprite frame dimension is not a list count. Packet hardware meaning and the rest of the handler remain outside this result.

Current Rust tests exhaust all 256 offset values and check six twelve-line rows, lower/upper coordinate edges, i32 extremes, event/flag gating and byte wrap.
