# Independent full-viewport assembly

The shared viewport renderer passed 39 native cases: 33 complete 640×480 indexed frames, 10,137,600 final index pixels, 13,000,128 ordered writes and 13,840 ordered dirty requests. Fourteen frames use the gated initial columns 4–19, including seven explicit GENEPANL copies; the remaining frames use the full-width diagnostic. The oracle composes this lane's independent cached strip traversal, repeated triangle stepping, packed mode-5 carry model and mode-specific sampling. It does not import the Ghidra validators' mathematical models. See [the receipt](terrain-view-review.json).

Cases cover exact CONQ001 snapshots at three cameras, an explicitly applied pure factor plan, generated debug flags and a mode-0→6→15 fixture. All twenty columns clip to the complete frame. Base and optional calls preserve strip order, mode 6 retains prior pixels for transparent samples, and mode 15 reads the destination produced by preceding draws. Dirty requests retain their order and inputs remain unchanged.

Missing MAIN.GLA rejects when mode 15 is requested, and is accepted when no such request occurs. Unsupported texture selectors reject textured mode 5, while geometry-only mode 0 requires no texture access. Invalid cameras and atlas size reject. The function owns its newly allocated frame and returns no partial frame on error. No further defect was found.

The twenty-column interval is a full-width diagnostic policy. The separate initial API follows the [viewport context gates](viewport-context-review.md): columns 4–19, temporary flag 4, inherited initialized pitch 640 and blank left margin before explicit panel composition. Supplied cameras, factor snapshots and other context flags remain explicit inputs. Panel-copy validation preserves the entire view on failure, and leaves terrain and metadata unchanged on success. GENEPANL is a diagnostic choice while its initial selector remains unresolved. These comparisons do not establish live callbacks or original runtime scene parity. No original executable or GUI ran.
