# Independent owned plant world and headless adapter review

**Passed:** 1,100 real-source scheduler passes and55 sequential callbacks matched the independent model byte-for-byte across378,353,800 state bytes. At attempted pass1,101, record10 reaches the unimplemented reproduction/RNG branch. The native world rejects it and preserves every byte, cursor and tick number. This is a proved suspension boundary, not silently skipped reproduction or a complete original tick.

The oracle starts from the exact CONQ001 and executable-mapped twelve-record parameter table. It independently computes geometric toroidal neighbor counts, original-floor terrain fallback, word/byte arithmetic, per-category retirement, source-list rewiring and scheduler order. Native queued indices, counts, cursors and every packed byte are compared after each successful pass. Membership/position/count invariants are rechecked independently. Other families, original callback side effects, UI/audio/reference cleanup and host cadence remain explicitly suspended.

Three concrete mismatches were reported and corrected before the passing replay: retirement must preserve the removed record's own links; a singleton head removal clears only its kind byte while retaining index bytes, and non-singleton rewiring copies raw reference triples; zero-class terrain fallback uses the original floor cell rather than the rounded cell. Null references can contain preserved index data, so canonicalizing them changes bytes even when traversal still stops correctly.

The current `genewars-game` headless menu/loading route also produced exact expected world bytes at steps0,1 and128, using the same source-bound resources. Extreme signed32 pointer coordinates miss the menu without overflow after the reported subtraction fix. Native GUI was not launched by this review. The first two retirements are outside the displayed plant subset, so a changed world need not change that frame; visible change is not fabricated.

The adapter's render policy is explicit: clone the world map, apply the development factor-raise view, refresh projected shade, draw the admitted plant-only queue and use GENEPANL backing. These rendering choices do not mutate world visibility or establish original first-scene state. The game clones the proposed world and renders a proposed frame before committing both; lower-level native rollback was exercised at reproduction, while the whole adapter was compared through128 steps. The review does not claim raw original framebuffer parity, travel/work commands, AI or a complete mission startup.
