# Independent family-1 queue review

**Corroborated:** no mismatch was found in `queue_family1`, `family1_draw_packet` or `family1_admission_packet` against the pinned instruction contracts and independently implemented native comparisons. Reproduce with `python -B research/variants/entity-queue-review.py`; exact pins and counts are in the adjacent JSON receipt.

The independent reference represents actual head pointers and next links. It compares 277,831 queue requests and 190,479 resulting ordered entries with native output, including all signed initial-count and margin words, all signed16 coordinate values on both axes, every high-word coordinate pattern, signed32 extrema/boundary crossproducts, all 257 capacity reservations, 5,040 mixed bottom-bucket permutations and 4,096 mixed explicit sequences. Candidate input slices remain unchanged. IDs are opaque and may repeat; neither ID order nor source order supplies the ordering rule.

The bucket-479 mixture is significant: ordinary y=479 inserts at the head, y=480 has the same residual zero but appends stably among existing zero residuals, and higher offscreen y sorts by residual. Bottom output is y-1. Top residuals are stable ascending; ordinary on-screen ties reverse admission order. Full signed32 projected bounds are checked before signed16 storage, and the active-module/capacity gates are explicit.

All 131,072 gate/mode/flag draw packets match, along with 2,359,296 admission packets spanning every flag/shade pair, every signed countdown byte, all native-type/context bytes, prior context gates and old-frame-null states. Shade zero preserves both flags and the existing gate. Positive shade raises the gate; a positive signed countdown sets mask 4; mask 4 requests dirty marking and sets mask 8. A null old frame suppresses the dirty routine body without undoing the flag change. Draws require the shared gate and either nonzero mode or mask 8, then clear masks 4 and 8 only. Rejected packet preconditions remain distinct from a skipped draw.

The thirteen instruction hashes, native type-2 dispatch table and family-1 virtual targets were checked. The formal ordering/packet JSON vectors match the separate model. An independent height/projection calculation for the forty raw CONQ001 family-1 points reproduces the seven admitted points and their ordered fixture at explicit camera [66,48], margin 128.

This establishes only pure queue/packet behavior for explicit inputs. An initial nonzero count reserves shared capacity; the result contains newly admitted family-1 entries and does not merge or traverse preexisting other-family chains. No dirty prepass, actual callbacks, global queue reset, selected-entity interaction, full first-scene order or live shade refresh is executed or inferred. Negative original counts are safely rejected, rather than reproducing unsafe source indexing.
