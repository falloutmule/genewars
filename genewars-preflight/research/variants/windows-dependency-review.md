# Local Windows dependency integrity and license receipt

Observed: the project's actual target is x86_64-pc-windows-gnu, selected by its private Rust 1.99.0 toolchain. The actual Cargo normal/build tree contains 24 registry packages, 17 in the winit/softbuffer dependency closure (including shared packages). `windows-dependency-review.py` resolves offline with the pinned lockfile, captures the target-specific tree, verifies every cached .crate SHA-256 against Cargo.lock, and compares every archive file byte-for-byte with the extracted source. All archive/source checks pass. The complete metadata-only result is `windows-dependency-review.json`; raw Cargo metadata remains private.

Winit 0.30.13 declares Apache-2.0 and includes the Apache license text. Softbuffer 0.4.8 declares MIT OR Apache-2.0 and includes both license texts. Their exact archive checksums are pinned in the JSON. Winit's actual features are only `rwh_06`; softbuffer has defaults disabled and no activated optional features. Every package in the new backend closure has a license payload. Manifest license expressions, payload hashes and identifying text-family markers were checked locally; no source or license text was copied into the reconstruction.

One inherited dependency has a packaging gap: winapi-x86_64-pc-windows-gnu 0.4.0 declares MIT/Apache-2.0 and points to retep998/winapi-rs, but its archive's include list excludes license files. Its archive/source integrity passes; the receipt does not claim its own cached license payload exists. Parent winapi 0.3.9 in the same graph does include license texts. Applicable notices should accompany any later distribution; no distribution is performed here.

Cargo metadata can unify optional features from other workspace or target graphs, so this review uses the actual target-specific normal/build Cargo tree to filter packages and report activated features. It does not label those extra metadata nodes as build dependencies. MSVC is not verified: its windows_x86_64_msvc 0.52.6 package is absent from the local cache and the offline query rejects a download. No network, global settings, GUI or original execution occurred during this audit. Other targets and source-wide legal conclusions are outside this metadata receipt.
