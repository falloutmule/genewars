# Independent packet and bounded-name review

Observed: the current core ports match the restricted static contracts. `core-control-review.py` compiles an independent Rust harness that calls the actual core modules without editing them or running a GUI/original. `core-control-review.json` pins the reviewed sources, harness and private instruction hashes.

For mode2 button packets, direct VA 0x70EF5–0x70F87 instructions give press-latch priority, optional release from prior packet-held bit, and next-held true. With no latch, physical-held clears both event bits and sets held; otherwise old held becomes release and held clears. The harness transcribes those byte masks and checks all 256 prior packet bytes × two latch states × two physical states: 1,024 cases. No defect found. A newly received press notification must set the host latch whenever it is empty even if physical-held was already true. Hit coordinates must come from current packet-production position; the separately retained first-press coordinates are not those fields. The producer does not establish a host tick interval.

For names, the initializer zeroes exactly 0x8CA bytes at screen+0x507 and clears count+0xDD1. Maintainer 0x7EF30 gates insertion at count<10 and walks stride225, with names at +0xE and following copied metadata at +0x30. Requiring NUL within [0xE,0x30) is a conservative safe-port rule, explicitly documented rather than attributed to the unchecked original. The implementation validates count≤10, selected<count and full 2,250-byte storage before constructing any slice. The harness checks all 65,536 count/selection combinations, all 2,250 truncated lengths, every one of 34 NUL positions in all ten slots, and rejects a terminator only in the following field. No defect found; returned bytes do not guess a text encoding.

Scope excludes original callback races, complete input packet fields, mouse mickey scaling, incoming list record semantics, guaranteed original terminators and unchecked original copies. The source is the provisional CD candidate, not proven canonical retail behavior.
