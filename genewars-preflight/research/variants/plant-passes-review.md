# Independent normal plant pass review

**Corroborated:** the current foreground, normal component shadow, and composed helper match the independently implemented parser/raster oracle for the pinned CD resources. No production mismatch was found. Run `python -B research/variants/plant-passes-review.py`; exact source/resource/instruction hashes and counts are in `plant-passes-review.json`.

The review compares all 108 selections from twelve resources and nine animations, plus three synthetic selections exercising a nonzero animation-relative first frame, multiple overlapping components, signed odd component coordinates, short/empty RLE rows, and opaque index zero. Native cached metadata, complete index planes, opacity masks and stream consumption match the separate Python decoder for 114,628 source pixels.

Across 339,594 draw cases, 26,442,504 destination bytes match. Cases include all 65,536 flag/shade pairs, all signed-word foreground origins and shadow Y offsets, every GLA color/destination pair, direct/FADE branch boundaries, full signed32 caller origins, positive/negative clipping, row padding, exact minimum extents and offset-128 views with width 512/pitch 640. Twelve independent shadow fixture hashes also match the separate static lane receipt. The synthetic GLA is deliberately asymmetric, so reversing color/destination order fails these comparisons.

Foreground narrows the origin and each component sum to signed16. Shadow adds the signed component x using full signed32, halves signed component y with truncation toward zero, and samples odd source rows only. Shadow uses `GLA[color*256 + prior_destination]`; literal color values are ignored while run-derived opacity is retained. Composed draws complete all component shadows before any foreground component; rejected dispatch/table/extent cases leave the caller's bytes unchanged.

The native checks also reject 76,863 parser inputs (every truncation of twelve resources, invalid animation/frame selectors, malformed section/component references and unsupported component flags) and fourteen malformed public sprite-plane or arithmetic/extent cases. The extended raw family-1 fields match 3,072 records from five pinned actual missions and one synthetic mission spanning every byte selector; negative signed resource selectors remain distinguishable from their raw bytes.

These are pure API/static comparisons, with no original execution. They do not establish live entity order, visibility, animation timing, initial scene state or a complete scene renderer. Cache decoding requires complete row terminators and bounds streams before metadata, which is stricter than an original clipped early return. The shadow API rejects zero clip dimensions; no original zero-clip equivalence is claimed. The foreground receipt explicitly leaves shadow pending, while the separate composed helper completes only these two admitted passes. Caller-selected resource identity and the exclusion of unsupported context/flash/jitter/component paths remain explicit.
