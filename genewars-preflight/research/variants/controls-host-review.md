# Independent controls-host review

The current host implements the restricted packet/capture contract with explicit diagnostic scheduling. Ordered button-down notifications set an empty press latch even if physical-held was already true. The first press position is retained only as a separate latch diagnostic; hit testing uses the latest cursor position at packet production. A queued down/up pair still creates a press packet followed by a release packet. Selected state is rendered through the actual component offset and 19×32 sprite opacity, with original control list order resolving the shared scanline. Release activates the captured control even outside its hit pixels.

Physical cursor mapping uses the same floor relation as nearest-neighbor framebuffer sampling. My review found i32 subtraction overflow for extreme public hit-test coordinates; Luna changed subtraction to i64 and added MIN/MAX tests. The bounded GUI coordinates were unaffected, but the public API now safely returns no hit. Renderer unit tests passed 11/11 in this lane. `controls-host-review.py` records current source hashes and runs the separate host's pure unit tests without creating a GUI; its JSON stores actual results.

The first host test build failed because bundled GNU DLLTool could not spawn an assembler. Root supplied private LLVM tooling and the subsequent unit build passed. This compiler prerequisite is separate from the reviewed 24-package Windows registry dependency receipt. No compiler files were changed by this lane.

Raw transitions, packets and activation IDs have bounded traces with explicit dropped counts. The nominal 60Hz schedule is a host choice; `--frames` limits packet updates, while the report counts successful presentations separately. Focus changes are deliberately ignored and focus-loss recovery is not claimed. Native event delivery, cursor ordering and human click behavior require root's separate private UI observation; unit tests and frame counts alone do not prove them. No GUI or additional original was launched by this review lane.
