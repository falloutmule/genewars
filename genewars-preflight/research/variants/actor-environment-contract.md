# Owned actor environment contract

This bounded contract covers terrain class, blocker weight and obstacle absence for the currently owned first-mission states. It supplies actual map/list queries rather than caller booleans. The attached script checks private instruction hashes, mapped virtual targets and the exact mission. No original or emulator executes; no native query implementation is claimed tested yet.

`terrain_class(map229376, position:[i16;2]) -> 0..7`: direct8B520 reads cell+5 low3bits at the nearest vertex, independently incrementing each high coordinate byte when its low byte is>=128. Wrap grid indices modulo128. Return that class if nonzero. Otherwise test **eight neighbors around the original floor cell, excluding the original center**; return1 if any has nonzero low3bits, else0. This is unrelated to texture orientation. The original-center-only counterexample exposed a bug in the prior owned world/model; root and SOL-01 are correcting their owned files, and the independent runtime trajectory oracle was corrected/replayed.

`cell_plant_blocker(actor_handle, point) -> weight` for native type3 actors follows8B130:

If the plant's floor cell equals the query cell, return zero for the entire cell. Otherwise remember that plant as an exclusion. Other target kinds do not interpret the opaque index word.
3. Traverse the current cell list with actual family bounds, ID/type consistency and duplicate/cycle checks. Skip the querying actor. Apply the proved virtual slot10 predicate, skip the nominated plant, then add10 for each type2 plant whose native byte2E mask08 is clear. Do not substitute growth, retirement bit80, shade or resource selector for this bit. At most512 distinct plants imply weight<=5120.

Current reachable kinds are1 (one record) and2 (forty plants), with newly owned actors kind3. Virtual10 for kinds1/3 resolves1EE20, native byte4A mask04; kind2 resolves1F410, alwaysfalse.
