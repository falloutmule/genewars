# Interactive native menu host review

No blocking finding in the current Windows x64 host and main refactor. Source hashes match the exact binary/report/capture pinned by the operator observation. Its actual normal BMP matches all307200 pixels of the independently composed menu oracle. The separate campaign-menu review also compared both title frames, the complete normal hit mask and128000 controller packet cases.

This host emits a manager packet immediately for each delivered cursor event, right-button event, changed left-button state and focus loss. It preserves their delivery order but does not call the original mode2 packet producer, retain its asynchronous press latches or reproduce its sampling cadence. Duplicate unchanged left notifications are suppressed. The separate controls inspector has a nominal60Hz producer; that cadence does not apply here. These are explicit host adapter choices, not original input parity.

Pointer mapping uses current physical client size and floor scaling into640×480. Out-of-client, zero-size and NaN positions miss; valid positions keep signed hit subtraction safe. Hit traversal preserves list order and disables ID1. The captured control uses its normal opaque footprint while selected artwork changes. Input-mask writes retain absence versus zero; activation requires returned ID and mask8 together. Source reasoning and the separate controller review support outside-release and hover behavior, though these were not observed as actual held interactions.

Focus loss resets host cursor/button state and sends an outside release, deliberately cancelling capture without activation. Escape and CloseRequested exit via events. A successful buffer presentation increments the frame counter; zero-size windows do not. Positive frame limits count presentations, not wallclock time or physical monitor refreshes. Without a limit, the host waits for events and redraws on selection/resize. A minimized window can wait indefinitely. The fixed-size image set and Windows64 arithmetic bound scaling; no32-bit claim is made.

Main composes four640×480 states with the same bound background/font/text/palette inputs. It writes the normal BMP exclusively, records scene requests and refuses output overwrites. ID0/3/2 requests are not dispatched to campaign/Options/Quit scenes. Root observed a transparent-corner miss, requests0/3/2 and Escape exit0; held appearance, release outside and focus cancellation remain static/synthetic evidence. The JPEG is a host-window capture, not a raw framebuffer.

The prior `menu-window-review.md` concerns the earlier static host. This note and `menu-event-host-review.json` supersede its no-hit-mapping statement for the new interactive version. No GUI or original was launched by this reviewer.
