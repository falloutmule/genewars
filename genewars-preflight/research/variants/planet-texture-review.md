# Independent numbered planet texture review

**Corroborated:** `PlanetTextureAtlas::parse`, `.tile`, and `PlanetTextureTile::is_opaque` match the bounded source-texture behavior identified for the exact CD candidate. No implementation defect was found. The review covers PL1–PL4 source bytes and explicit tile types 0–13, independently of the active reference session.

Direct disassembly sets mode 3 at `0x192DB..0x192E3`. The large-tile branch reads an unsigned type byte and computes a column of `(type & 1)*128` and a row of `(type >> 1)*128`; each source row has 256 bytes. The small-tile branch at `0x19434..0x19474` subtracts 8, divides the nonnegative admitted value by four, shifts row groups by 64, adds row 512, and masks the horizontal displacement to one byte. This yields columns 0,64,128,192 for types 8–11 at row 512, and columns 0,64 for types 12–13 at row 576. The port's two offset expressions agree.

The mode-3 sampler zeroes EBX, places the low integer U byte in BL and low integer V byte in BH, and reads `texture_base + EBX`. Its `OR AL,AL` / `JZ` skips a destination write for zero and copies nonzero AL unchanged. Thus the extracted indices retain their source values, and `index != 0` is the evidenced opacity rule. No palette lookup is part of this sampler branch.

The port's exact 163,840-byte admission follows the four observed decoded PL resources. It is a safe restriction for this API, not a general guarantee about unrelated files. The 14 extracted tiles use 155,648 distinct bytes per atlas with no overlaps; the largest addressed byte is 163,711. The remaining 8,192 bytes per atlas are uninterpreted. The fixed bounds also keep row multiplication and output allocation bounded. Checked coordinate multiplication and slice access keep `is_opaque` safe even if a caller mutates the tile's public fields into inconsistent dimensions.

Run `python -B research/variants/planet-texture-review.py`. A private native harness imports the actual assets source, freshly decodes the four hash-verified original PL resources, and writes every tile index and every opacity byte privately. An independent Python gather uses explicit atlas row/column placements, checks each source address, and compares every byte with the native results and the static evidence hashes. All 56 tiles, 622,592 indices and 622,592 opacity bytes matched; 378,446 pixels were opaque. Native checks also reject all 242 unsupported u8 types and five malformed lengths, and check out-of-range/overflow opacity coordinates. Seven private listing hashes and the candidate executable hash were verified. `planet-texture-review.json` records exact reviewed source, harness, input, output and evidence hashes.

This review establishes neither RGB colors nor complete planet drawing. Palette association, fixed-point interpolation, projection, clipping, destination positions, draw order, and original timing remain excluded. The unrelated `PLANETS.DAT` consumer remains unproven; this API does not parse it or pair CD textures with another build's animation data. No original program or GUI was executed by the review.
