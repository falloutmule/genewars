# Independent creature packed4 review

Observed: the explicit caller-selected packed4 decoder passes independent full pixel and full opacity-mask comparisons for all 2,673 active records in the 25 admitted creature inputs (50 source aliases). The receipt is `creature-review.json`; rerun with `python -B research/variants/creature-review.py`. Only our Rust research tool is executed. Source pixels, masks and synthetic fixtures stay private.

The independent Python decoder traverses only the actual sprite extent `[18, section0)`, checks the separately embedded six-byte table, and compares each result with both cached native consumed/opaque counts and fresh native full output. It verified 134,009 rows, 1,661,696 opaque pixels, 107,328 odd positive runs and 7,105 zero nibbles. There are zero row-width overshoots and zero metadata-boundary crossings. 125,714 rows end before the declared width; these are legitimate zero-terminated rows with a transparent remainder, not a demand to consume another row. All 25 empty descriptors remain empty. No next-sprite offset is treated as a hard boundary.

Direct listing review corroborates the distinct grammar: VA 0x8FC08 skips a positive run using `ceil(N/2)` packed bytes; 0x8FCCE and 0x8FD2D extract high nibble before low; 0x8FD72 uses only the high nibble for an odd tail; 0x8FD8B advances the entire packed payload even when visible writes clip. The no-translation branch stores unsigned base-plus-nibble modulo 256. This agrees with the independently implemented Rust decoder. The admission receipt pins the loader and caller chain, and all seven private listing hashes were rechecked. Its 25-hash policy is explicit; generic indexed8 is unchanged.

Fresh full outputs at base 250 also match for one active record from each input. Independently specified base-0 and base-254 vectors check ignored odd low padding, opaque nibble zero, transparent skip, clipped positive runs consuming their full payload, and palette wrap. Removing a required final row terminator is rejected. These checks do not claim the original always reads the final zero when the last visible row exhausts width; complete-height safe parsing is the API's documented scope.

The former full-file indexed8 receipt remains preserved at `full-file-sprite-corpus-superseded.json` with SHA-256 `e37e4ff54416f90d9192b8ba5de0f650770be9fd087bd2cffff6c62c02a931f2`. Its 480 metadata-crossing traversals were real defects in that diagnostic policy, rather than proof of damaged input. The new code selects the statically proven packed4 grammar only for admitted creature sources and retains strict section bounds.

Unknown or excluded: BONES and GPF, translation-table lookup (which indexes base+nibble before any wrap), actual runtime palette-bank association, scaled/flipped/lighting paths and animation timing. Structural and static correspondence here does not establish gameplay or framebuffer parity.
